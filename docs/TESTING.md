# Testing

`uv run --no-editable --extra dev pytest` runs offline unit/integration tests;
`uv run --no-editable python main.py doctor` checks binary and model
availability. MP4 integration tests
use actual FFmpeg/FFprobe when present and label synthetic footage. Tests
cannot establish that a rights declaration is authentic, that a citation
semantically supports all wording or that a clip depicts the named species:
these need independent operator review. Benchmark VideoToolbox, MLX memory
and whisper accuracy on the production Mac before claiming them validated.
